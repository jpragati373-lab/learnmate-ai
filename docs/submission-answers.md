# Submission answers

## Project Name

LearnMate AI

## Tagline

Understand. Practice. Improve. Remember.

## Challenge

AI for Learning

## Problem Statement

Students often consume explanations without reliable evidence that they understood them. Generic tools rarely connect explanation, practice performance, weakness detection, revision timing, and progress measurement in one workflow.

## Solution

LearnMate AI turns a difficult topic into a complete learning loop: understand it with a level-aware explanation, practise it with an adaptive quiz, evaluate the result, detect weak topics, receive an explainable recommendation, revise at the right time, and measure progress.

## Target Users

College students, competitive-exam learners, and self-learners studying technical or academic subjects.

## Key Features

- AI Concept Explainer
- Personalized Learning Paths
- Adaptive Quiz Engine
- Weak Topic Detection
- Explainable Recommendations
- Smart Revision
- Learning Analytics
- Contextual AI Study Assistant
- Responsible AI disclosure
- Accessible responsive interface
- Clearly labelled demo/fallback mode

## What Makes It Innovative

Traditional learning tools often separate explanation, assessment, revision, and progress tracking. LearnMate AI connects them into one continuous loop:

**Understand → Practice → Evaluate → Detect Weakness → Recommend → Revise → Measure**

It is a learning system rather than a generic chatbot.

## How AI Is Used

AI-powered decisions include:

- Concept explanations
- Learning-path generation where applicable
- Quiz generation
- Contextual tutoring
- Misconception explanations

Deterministic application logic owns:

- Quiz scoring
- Accuracy calculation
- Weak/strong classification
- Difficulty adjustment rules
- Revision scheduling
- Analytics calculations
- UI state and navigation

## Tech Stack

React, TypeScript, Vite, React Router, Tailwind CSS, Recharts, Express, Zod, CORS, dotenv, and an OpenAI-compatible chat-completions provider.

## How the Product Works

Landing → onboarding → dashboard → learning path → AI explanation → assistant → adaptive quiz → quiz result → weak-topic detection → recommendation → revision → analytics.

## Impact

LearnMate makes the next learning action visible and explainable. It helps students move from passive understanding toward deliberate practice and timely revision. The demo demonstrates the workflow with deterministic sample learning records; it does not claim guaranteed or scientifically validated learning improvement.

## Responsible AI

LearnMate uses AI as a learning assistant rather than an unquestionable authority. AI-generated explanations and questions may contain errors, so students should verify important information. Uncertainty is not hidden, provider credentials remain server-side, inputs are validated, and fallback content is labelled.

GitHub Copilot and other AI tools were used where applicable for development assistance, debugging, documentation, UI work, testing support, and prompt development. The developer reviewed, tested, modified, and integrated the resulting implementation.

## Security

Provider keys are server-side only. Requests are validated with Zod, CORS uses a configured client URL, assistant requests are rate-limited, quiz answer keys are not sent with public questions, JSON body size is limited, and errors do not expose stack traces.

## Accessibility

The interface uses semantic headings, labelled inputs, keyboard-friendly controls, visible focus states, accessible button names, readable contrast, text summaries for charts, and status text that does not rely only on colour.

## Limitations

The current build has no authentication, database persistence, multi-user isolation, verified deployment, or unrestricted document upload. Demo state is static/in-memory, and AI output can be incorrect.

## Future Roadmap

Authenticated student profiles, persistent progress, secure document ingestion, richer question types, validated spaced-repetition personalisation, multilingual learning, and teacher/mentor tools.

## Short Project Description — Version C — 100 words

LearnMate AI is a personalised learning and practice platform for students studying difficult technical and academic concepts. It explains a topic at the learner’s level, provides examples and knowledge checks, generates adaptive quizzes, evaluates answers, detects weak and strong topics, recommends what to study next, schedules revision, and visualises progress. AI supports explanations, question generation, misconception guidance, and contextual tutoring, while deterministic application logic owns scoring, classifications, revision timing, recommendations, and analytics. When an external provider is unavailable, clearly labelled demo content keeps the core workflow usable. LearnMate AI closes the gap between understanding a concept and actually mastering it.
