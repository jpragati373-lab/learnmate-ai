# Responsible AI

- **Disclosure:** Explanations show an AI-generated or Demo content label; assistant fallback messages show Demo response.
- **Verification:** AI output may hallucinate. Students are prompted to verify important academic information with trusted sources.
- **Human control:** Scoring, weak-topic classification, progress, recommendations, revision dates, and analytics are deterministic application logic.
- **Privacy:** The demo collects only learning preferences required for the experience. It has no authentication or persistent personal profile database.
- **Security:** AI keys are read only by the server. Request schemas limit content sizes and assistant requests are rate-limited.
- **Scope control:** The application does not execute model output as code and provides no arbitrary code-execution feature.
- **Conversation minimisation:** Assistant history is limited before provider requests and is used only to preserve the current learning context.
- **Input validation:** Topic, level, learning style, quiz, and assistant inputs are validated before processing.
- **Fallback mode:** Provider timeout, unavailable provider, or invalid structured output uses clearly labelled deterministic demo material.
- **Academic integrity:** The assistant is designed to explain, question, and coach rather than silently complete assessed work.
- **Limitations:** Demo state is not multi-user isolated and AI responses are not a substitute for an instructor or authoritative source.
