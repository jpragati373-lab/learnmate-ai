# LearnMate AI two-minute demo script

Use the local app or the verified public deployment. If using the local fallback, keep the visible `Demo content` and `Demo response` labels; do not describe fallback output as live provider output.

## 0:00–0:15 — Problem

**Narration:**  
“Students can receive an explanation and still not know what they misunderstood. Practice is often random, weak topics stay hidden, and revision happens too late. LearnMate AI connects those missing steps into one learning workflow.”

**Action:** Open the landing page `/` and point to the tagline and the learning-loop value proposition.

## 0:15–0:35 — Solution

**Narration:**  
“LearnMate starts with a difficult topic, explains it at the learner’s level, builds a path, tests understanding, evaluates the answers, detects weak topics, recommends the next action, schedules revision, and makes progress visible.”

**Actions:**  
1. Click **Start Learning**.
2. Complete or skip through onboarding using non-sensitive sample preferences.
3. Open **Dashboard**.
4. Open **Learning Path**.
5. Select **Computer Networks** and **Subnetting**.

## 0:35–1:15 — Live product demonstration

**Understand — 0:35–0:48**

1. Open **Learn** or **AI Concept Explainer**.
2. Enter `Subnetting`.
3. Select **Beginner**.
4. Select **Simple explanation**.
5. Click **Explain with AI**.
6. Show the explanation, analogy, step-by-step section, example, common mistakes, quick summary, and knowledge checks.
7. Point out the AI verification notice and the `Demo content` label when fallback mode is active.

**Practice — 0:48–1:05**

1. Click **Quiz Me**.
2. Select **Computer Networks → Subnetting → Beginner**.
3. Start the five-question quiz.
4. Record the question IDs if demonstrating no-repeat behavior.
5. Choose an answer and click **Submit Answer**.
6. Show that feedback and the explanation appear after submission, not before.
7. Complete the quiz and open **Quiz Result**.

**Evaluate and improve — 1:05–1:15**

1. Point to the actual score and accuracy.
2. Show the topic classification: Weak, Needs Improvement, or Strong according to the actual result.
3. Show the resulting recommendation and **View revision** action.

## 1:15–1:40 — AI/adaptive learning differentiation

**Narration:**  
“The important difference is that AI is not the whole product. The model helps explain concepts and generate learning content, while deterministic application logic owns scoring, topic classification, adaptive difficulty, revision timing, recommendations, and analytics.”

**Actions:**  
1. Open **Revision** and show the review scheduled from the actual result.
2. Open **Analytics** and show progress, quiz accuracy, questions practiced, topic performance, and activity.
3. Return to **Practice** and start another Beginner Subnetting quiz.
4. Show that previously served questions are excluded when unused questions remain.
5. Optionally switch to **Intermediate** to show that difficulty history is independent.

## 1:40–1:55 — Impact

**Narration:**  
“LearnMate makes the next learning action visible and explainable. It helps a student move from passive understanding toward targeted practice and timely revision. These are intended product benefits, not a scientific claim or guaranteed outcome.”

**Action:** Return to **Dashboard** and point to the recommendation, weak/strong topics, revision state, and recent activity.

## 1:55–2:00 — Closing

**Actions:**  
1. Open **AI Study Assistant** with context **Computer Networks → Subnetting → Beginner**.
2. Ask: `Explain subnetting in a simpler way.`

**Narration:**  
“LearnMate AI does not simply answer a student’s question. It creates a complete loop that explains, practises, evaluates, detects weaknesses, recommends, revises, and measures.”
