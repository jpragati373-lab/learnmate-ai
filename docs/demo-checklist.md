# LearnMate AI two-minute demo checklist

## Product flow

- [ ] Landing page
- [ ] Dashboard
- [ ] Learning path
- [ ] AI explanation
- [ ] Quiz
- [ ] Quiz result
- [ ] Recommendation
- [ ] Revision
- [ ] Analytics
- [ ] AI assistant

## State and quality

- [ ] Clean new-user state
- [ ] Demo Mode separation
- [ ] No repeated questions
- [ ] No console errors
- [ ] Responsive UI
- [ ] Accessible labels and controls
- [ ] Loading and fallback/error states understood before presenting
- [ ] Two-minute timing rehearsed

## Demo setup

- [ ] Backend is running with `npm --prefix server start`
- [ ] Frontend is running with `npm --prefix client run dev`
- [ ] Browser opens the verified local or public frontend URL
- [ ] Normal learner state is reset before the demo
- [ ] Computer Networks and Subnetting are selected
- [ ] Beginner difficulty and Simple explanation are selected
- [ ] Fallback content is described as `Demo content` if the AI provider is unavailable
- [ ] Any Demo Mode sample data is explicitly labelled `Demo Mode — Sample learning data`
- [ ] Quiz 1 IDs are recorded if demonstrating no-repeat behavior
- [ ] Quiz 2 is generated only after Quiz 1 so history filtering can be demonstrated

## Presenter reminders

- [ ] Do not claim sample values are real learner statistics
- [ ] Explain that scoring, classification, recommendations, revision, and analytics are deterministic application logic
- [ ] Explain that AI-generated content should be verified
- [ ] Do not claim the retention indicator is scientifically validated
- [ ] Keep the closing statement within the two-minute time limit
