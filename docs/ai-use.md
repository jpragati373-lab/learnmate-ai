# AI use declaration

AI development tools, including GitHub Copilot and conversational AI tools where applicable, assisted with:

- Code generation and refactoring
- Debugging and API integration
- Architecture brainstorming
- UI implementation
- Documentation
- Test generation and validation planning
- AI prompt design

The developer reviewed, tested, modified, and integrated AI-assisted output and remains responsible for the final implementation. AI-generated output was not accepted blindly, and the application separates model suggestions from deterministic scoring, progress, recommendations, revision scheduling, and analytics logic.
